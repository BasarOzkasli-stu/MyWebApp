# Contributing to MyWebApp

Thank you for your interest in contributing to **MyWebApp**!

## Code Review Process

All pull requests require at least one reviewer approval before merging.

### Collaborators and Reviewers
- **BasTunKar** - Code reviewer

## How to Contribute

1. Fork the repository or create a new branch from `main`
2. Make your changes with clear, descriptive commits
3. Open a Pull Request referencing the related issue (e.g. `Closes #4`)
4. Request a review from a collaborator
5. Address any review feedback
6. Merge once approved

## Branch Naming Convention

- `feature/<short-description>` - New features
- `fix/<short-description>` - Bug fixes
- `docs/<short-description>` - Documentation updates
